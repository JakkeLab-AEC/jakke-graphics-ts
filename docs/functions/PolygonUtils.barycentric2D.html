      Computes the barycentric coordinates (u, v, w) of a point p with respect to a triangle defined by vertices a, b, and c in 2D space.

      Barycentric coordinates are useful for interpolation, point-in-triangle tests, and other geometric computations.

      Parameters

      • p: Vertex2d

        The point for which to compute barycentric coordinates.

      • a: Vertex2d

        The first vertex of the triangle.

      • b: Vertex2d

        The second vertex of the triangle.

      • c: Vertex2d

        The third vertex of the triangle.

      • eps: number = 1e-12

        Optional epsilon value for floating-point comparison to avoid division by zero (default is 1e-12).

      Returns undefined | { u: number; v: number; w: number }

      An object containing the barycentric coordinates { u, v, w } if the triangle is valid; otherwise, undefined.
